# 纽约生活内容维护

## 已上线的内容类型

首页以活动与官方日历为主；看房、二手等分类和生活指南集中在桌面右侧、手机活动区之后的次要入口。指南正文和完整列表仍在纽约生活专区，不在首页铺开。

- `/en/living`、`/zh/living`：纽约生活入口，包含三篇原创双语清单、真实社区活动和官方活动日历链接。
- `/[locale]/living/[slug]`：独立指南详情页，中英文共享 slug，支持 canonical、hreflang 和 sitemap。
- 指南在 `lib/living.ts` 维护，通过 GitHub 版本管理发布；当前没有公开投稿接口，也没有宣称已提供指南 CMS。
- 生活内容是六大分类之外的编辑内容，不新增第七种分类信息。

## 指南更新

每篇指南应有唯一 slug、中英文标题/摘要/正文、所属话题、真实更新日期和官方 HTTPS 来源。只在实际修改后更新日期，不伪造阅读量、作者身份、评价或热度。涉及租房、资格、费用等可能变化的要求，应引用官方资源，不写未经核实的固定金额或保证。

本批内容为看房核查、二手交接和图书馆活动查找清单，不是转载新闻，不代表对具体房源、商家或活动作了真实性背书。新增内容前请核对来源和事实，保留必要的适用范围说明。

## 社区活动

使用已有发布流程：社区信息 → 本地活动，填写真实的活动日期及相关说明，提交后由管理员审核。纽约生活查询只读取已审核、发布有效、属于已启用纽约地区且活动日期为纽约当地今日或之后的记录；数据库先筛选并排序，再最多取三条。

没有日期、过去日期、未通过审核或过期的信息不作为近期活动展示。日期字段不能表达具体开始时间，因此页面不编造时间、报名名额、费用或“免费”标签。具体信息沿用原始发布语言；中英文界面切换不声称翻译用户投稿。

## 官方日历

NYPL、布鲁克林公共图书馆、皇后区公共图书馆及纽约市公园局的链接是查询入口，不是由 OofCourse 核实的具体活动，也不代表免费、已预约或仍有名额。外链在新标签页打开，带 `noopener noreferrer`，不会在 OofCourse 内模拟报名。

本次云端检查可读取 Brooklyn Public Library、MTA、FTC 和 NYC HPD 的页面。NYPL 未返回可解析正文，Queens 返回访问保护页面，NYC Parks 拒绝云端请求；没有绕过访问限制，也没有抓取或发布这些网站的活动数据。应由维护人员用普通浏览器定期检查入口及主办方信息。

## 后续运营工作

定期复核指南与官方入口；配置邮件和消息提醒；如需独立编辑后台，应新增受管理员身份及 RLS 保护的内容工作流，再启用发布功能。当前无需执行新 SQL，也没有设置自动抓取、每日自动发稿或付费活动服务。
