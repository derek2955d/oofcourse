# 一年内容展示样板

入口：`/zh/preview/activity-year`、`/en/preview/activity-year`。

按纽约日期生成 24 篇过去十二个月的内容概念，以及 8 条接下来 30 天的出游概念，供查看内容量、卡片对齐和归档体验。所有日期明确写作“示例日期”；不是历史发布记录，也不是主办方确认的未来活动。详情页有原创中英文正文、回到列表的链接；不提供虚假报名或购买入口。

样例由 `lib/activity-year-preview.ts` 提供，完全不读写 Supabase，不创建假用户、评论、流量、商家或交易。不会加入真实首页活动 feed、真实活动 API、站点地图或 Event 结构化数据；预览页与详情均 noindex/nofollow。`ENABLE_LAYOUT_PREVIEWS=false` 可统一关闭。没有修改真实站点的运营年限、创建时间或活动记录。

未来如需真实历史档案和未来活动，应逐条核实主办方来源、实际日期和素材许可，再通过管理员审核发布，不应直接导入这批样例。
