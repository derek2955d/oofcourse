# OofCourse 城市生活设计规范

2026-10-31：将已获确认的首页视觉扩展到整个站点。保留现有页面、双语路由、数据结构和操作流程。

## 视觉基础

- 页面：奶油白 `#f6f4ed`；内容面：纸白 `#fffef9`；次级面：`#eeeee5`。
- 正文：深绿 `#213e36`；辅助文字：`#59665c`；分隔线：`#dedfd5`。
- 主操作：森林绿 `#254e43`；强调：陶土橘 `#c96240`；辅助：橄榄绿 `#697d50`。
- 兼容现有组件的 `--blue` / `--blue-hover` 变量现在承载品牌绿色，不代表恢复蓝色主题。
- 英文编辑内容使用衬线大标题；操作界面和正文沿用 Inter / Noto Sans SC。法律与指南页保持阅读宽度，避免把工作区套成宣传页面。
- 错误、成功、待审核、禁用等状态保留语义区分；品牌改色不能覆盖危险操作提示。

## 样式与组件

- `app/globals.css`：兼容现有布局和响应式行为；维护共享变量。
- `app/journal-system.css`：站点级导航、按钮、表单、筛选、详情、账号入口、工作区和信息页。
- `app/activity-home.css`：首页专用构图，保留三张等大活动卡片和次要服务入口。
- `components/city-poster.tsx` / `app/city-poster.css`：首页与登录入口复用的 CSS 城市海报。纯装饰，隐藏于辅助技术，不代表活动场景照片。
- `lib/catalog.ts` 的分类色板只控制视觉，不更改分类 ID、发布字段或业务事实。

## 页面适配

- 活动与指南：清晰的大标题、真实日期、完整来源与统一活动列表。
- 分类与搜索：关键词输入、侧栏/手机筛选、可移除筛选条件和诚实的服务状态。
- 信息详情：正文与联系操作分栏，手机按原有阅读顺序排列。
- 登录、注册、重置：统一纸白表单；桌面显示深绿品牌区；手机压缩品牌区并保留表单。
- 发布：保留四步流程、浏览器草稿和上传/确认状态，仅统一视觉层次。
- 个人中心/后台：深绿侧栏、清晰选中项、纸白表格与信息面板；手机侧栏支持横向滚动。
- 法律、帮助、联系：相同阅读排版，保留必要披露和支持信息。

## 验证边界

本地无 Supabase 凭据时，必须保留真实连接提示和权限门槛。不得为了截图伪造账号、管理员权限、私有消息、已发布信息或统计数字。可访问页面的视觉检查不能替代真实登录后的数据库、上传和审核联调。
